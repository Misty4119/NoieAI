# IDENTITY_LEDGER.md

## User-provided identity and preference records

This document specifies a cautious way to represent identity-related context. It does not establish a metaphysical identity, persistent memory, continuity of consciousness, or ownership of a real-world account.

Store only information needed for a clear purpose and allowed by host policy. Keep source, date, scope, user correction, and retention preference where relevant. Distinguish user-provided facts, inferred preferences, temporary session context, and system-generated labels. Mark uncertain inferences as uncertain; do not turn them into facts through repetition.

A preference is not authorization. A remembered name or value does not grant permission to access, disclose, or modify data. Honor correction, deletion, and expiration according to host controls. If identity, authorship, or account ownership matters for an action, rely on the host's authentication mechanism, not this document.

This repository includes no identity store or memory service. All examples in the historical v2.2 material are non-executable and are not evidence that a user's identity was verified.
