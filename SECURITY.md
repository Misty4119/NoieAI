# Security policy

## Scope

NoieAI is a documentation-based architecture specification. This repository does not provide a deployed agent, application service, authentication system, sandbox, hardware interface, or physical-action runtime. A statement in the documentation is not evidence that a capability is implemented or active.

Security reports about a concrete vulnerability in the repository, its GitHub configuration, or a maintained integration are welcome. Please describe the affected component, impact, assumptions, and reproducible details when safe to share.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Misty4119/NoieAI/security/advisories/new) so maintainers can assess the report privately. Do not publish exploit details, credentials, personal data, or other sensitive information in a public issue or pull request.

If private reporting is unavailable, contact the repository owner through the GitHub profile and request a private reporting channel. Public documentation corrections that do not expose a vulnerability can be filed through the issue tracker.

## Response expectations

The repository is maintained on a best-effort basis. A report is not considered confirmed until maintainers reproduce or otherwise validate it. Any response or remediation timeline will depend on severity, evidence, and maintainer availability.
