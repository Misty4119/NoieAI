## 2. 弦論基礎

### 2.1 弦論概述

弦論提出基本粒子不是點狀的，而是振動的一維弦：

```

│                                                         │
│  不同振動模式 → 不同粒子                                 │
│  ┌───┐   ┌───┐   ┌───┐                               │
│  │ ○ │   │ ∽ │   │ ∧ │  → 電子、夸克、光子等         │
│  └───┘   └───┘   └───┘                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 弦的作用量

**Polyakov 作用量**（世界面描述）：

$$S = \frac{1}{2\pi\alpha'}\int d^2\sigma \sqrt{-h} \left( h^{\alpha\beta}\partial_\alpha X^\mu\partial_\beta X_\mu + \alpha'R^{(2)}\Phi \right)$$

其中：
- $X^\mu$：嵌入坐標（時空坐標）
- $h_{\alpha\beta}$：世界面度規
- $\alpha'$：弦張力（Regge 斜率）
- $\Phi$： dilaton 場

### 2.4 弦的振動模式

弦的振動模式產生不同的粒子：

$$M^2 = \frac{1}{\alpha'}(N + N_\perp - a)$$

- $N$：creation operators 的總數
