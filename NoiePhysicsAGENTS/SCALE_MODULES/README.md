## Status and model limits

Use the claim-status vocabulary in [Truth-OS epistemology axioms](../../NoieTruthAGENTS/EPISTEMOLOGY_AXIOMS.md). Classical mechanics, electromagnetism, thermodynamics, quantum mechanics, quantum field theory, and relativity are established predictive frameworks in specified domains, with assumptions and limits.

Quantum gravity approaches are proposals and remain unresolved. Interpretations of quantum mechanics are interpretations. Ryu–Takayanagi relations apply in specified holographic models. ER=EPR is a conjecture. Neither is a universal spacetime rule.

## Selection

Choose a module from the task's scale, state, precision needs, boundary conditions, and available evidence. For coupled scales, state how the models are connected and where approximations enter. If no model is suitable, return indeterminate rather than forcing a fit.

Loading this index does not automatically select or run a model. The runtime must attest any solver, simulator, sensor, or telemetry used. A simulation is conditional on its model and is not a proof of physical safety.
