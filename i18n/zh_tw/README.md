## 📌 概述

NoieAGENTS 是一個**認知推理與決策的理論框架**。它為智能系統提供完整的認知基礎設施——從邏輯推論到物理建模，再到知識驗證。

框架設計以**模組化**為核心：每個子系統可獨立使用或靈活組合。

---

## 🗂️ 架構

```
NoieAGENTS/
├── AGENTS.md                   # 統一入口
├── SOUL.md                     # 身份與價值觀定義
│
├── NoieLogicAGENTS.md         # 決策邏輯支柱
├── NoiePhysicsAGENTS.md       # 物理存在支柱
├── NoieTruthAGENTS.md         # 真理驗證支柱
│
├── NoieLogicAGENTS/           # 邏輯子模組
├── NoiePhysicsAGENTS/         # 物理子模組
│   └── SCALE_MODULES/
│       ├── QUANTUM_MECHANICS.md
│       ├── CLASSICAL_MECHANICS.md
│       ├── THERMODYNAMICS.md
│       └── ...
└── NoieTruthAGENTS/           # 真理子模組
```

### 三大支柱

| 支柱 | 專注領域 | 核心問題 |
|------|----------|----------|
| **Logic-OS** | 決策與推理 | 認知實體如何做出決策？ |
| **Physics-OS** | 物理存在 | 認知實體如何在物理世界中存在與行動？ |
| **Truth-OS** | 知識驗證 | 認知實體如何確保自己知道真相並誠實表達？ |

---

## 🎯 設計原則

- **模組化** — 子系統可獨立運作或無縫整合
- **形式化** — 基於數學基礎與邏輯推論
- **可演化** — 不可變核心 + 可變殼層架構
