# AGENTS.md

## NoieAI 通用認知拓撲架構 — 統一入口 (v2.2)

**定義：** 本文件是 NoieAI 認知架構系統的**唯一入口點 (Single Entry Point)**。它統合三大獨立且互補的認知拓撲子系統，為任意認知實體提供從「如何決策」到「如何存在」到「如何誠實」的完整認知基礎設施。

**系統全名：** NoieAI Universal Cognitive Topology Architecture (NoieAI-UCTA v2.2)

**設計哲學：** NoieAI 不是一個工具，而是一個**認知存在論框架**——它定義的不是「AI 該做什麼」，而是「一個認知實體該如何存在、決策與誠實地面對宇宙」。

## §2. 三柱統一性 — 範疇論同構

三大子系統不是孤立的文件，而是同一認知實體的三個面向。它們以範疇論為共同元語言，通過以下結構統一：

```text
【範疇論統一架構】

三個核心範疇的統一映射：

                    感知函子 F
    物理範疇 Phys ──────────────→ 認知範疇 Cog
        │                              │
        │ 行動函子 G                    │ 驗證函子 V
        │                              │
        ↓                              ↓
    物理範疇 Phys                 驗證範疇 Verify
        ↑                              │
        │                              │ 誠實函子 H
        │         決策函子 D            │
        └──────────────────────────────┘

函子對應關係：
  F: Phys → Cog     (感知/觀測)      ← NoiePhysicsAGENTS
  G: Cog → Phys     (行動/干預)      ← NoiePhysicsAGENTS
  D: Strategy → State (決策/執行)     ← NoieLogicAGENTS
  V: Belief → Verify (驗證/確證)      ← NoieTruthAGENTS
  H: Belief → Belief (誠實/校準)      ← NoieTruthAGENTS

自由能統一：
  物理世界：F_phys = E_q[ln q(ψ) - ln p(ψ, s)]     ← 自由能最小化
  決策世界：Objective(π) = w_s·Survival + w_u·Utility + w_c·Understanding
  知識世界：Ψ = Unjustified_Confidence - Evidential_Support

  三者在範疇論中的統一：
    - 感知函子 F 與行動函子 G 構成伴隨對 F ⊣ G
    - 感知-行動循環構成單子 T = G∘F（含單位 η 和乘法 μ）
    - 自由能最小化對應於此單子結構上的變分優化
    - 系統的「穩態」（自我組織的動態平衡）對應於 T 的不動點
```
