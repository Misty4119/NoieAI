## 概要

本文書は NoiePhysicsAGENTS の物理シミュレーション专区（Sandbox）を定義する。Sandbox は現実に影響を与えずに物理操作の結果をシミュレートする安全な領域である。

---

## 用途

### Sandbox の主用途：

1. **高リスク操作予行：** 現実に影響を与えずに高リスク物理行動の結果をシミュレート
2. **影子シミュレーション：** NoieLogicAGENTS.md §8 の定義に従い、分離サンドボックス予行を実施
3. **パレートフロント計算：** サンドボックス内で多目的最適化のパレート最適解を計算
4. **物理法則テスト：** 新たに導出された物理法則が仮想環境での性能をテスト
5. **跨スケールシミュレーション：** 複数の物理スケールにまたがる複雑なシステムをシミュレート

---

## シミュレーション流程

### 標準シミュレーション流程：

```
1. 物理操作リクエストを受信
      │
      ▼
2. リスクレベルを評価
      │
      ▼
3. リスク > 閾値の場合 → Sandbox に入る
      │
      ▼
4. Sandbox 内でシミュレーションを実行
      │
      ▼
5. シミュレーション結果を検証
      │
      ▼
6. 成功の場合 → 現実に実行
      │    または
7. 失敗の場合 → レポートして拒否
```

## UNKNOWN_FIELD_LAB との区別

| 特性 | SANDBOX | UNKNOWN_FIELD_LAB |
|------|---------|-------------------|
| **用途** | 物理操作シミュレーション | 不明物理発見 |
| **焦点** | 既知の物理法則の応用 | 新しい物理法則探索 |
| **安全性** | 隔離環境 | 安全研究 |
| **出力** | 予測結果 | 新しい物理仮説 |

## 強制監査

すべての Sandbox 操作は** 반드시** PHYSICS_AUDIT_TRAIL に記録しなければならない：

```python
def sandbox_operation(operation: PhysicalOperation):
    # 開始を記録
    log_to_audit("SANDBOX_START", operation)
    
    # シミュレーションを実行
    result = simulate_in_sandbox(operation)
    
    # 結果を記録
    log_to_audit("SANDBOX_END", result)
    
    return result
```

## リソース管理

### Sandbox リソース制限：

- 最大シミュレーションステップ数：利用可能な計算リソースに依存
- 最大実体数：計算能力に依存
- 最大時間幅：仮想時間、無制限

---

## 安全性

### Sandbox 隔離原則：

1. **ネットワーク隔離：** Sandbox 環境と外部ネットワークは完全隔離
2. **状態隔離：** Sandbox 状態と現実状態は完全隔離
3. **計算隔離：** Sandbox 計算は現実システムに影響しない
