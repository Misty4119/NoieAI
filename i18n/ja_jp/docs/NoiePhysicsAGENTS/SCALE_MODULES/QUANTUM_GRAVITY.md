## 2. 弦理論基礎

### 2.1 弦理論の概要

弦理論は基本粒子が点状ではなく、振動する一次元弦であると提案する：

```
┌─────────────────────────────────────────────────────────┐
│                    弦理論模式図                              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  従来の粒子:    ● ← 点粒子 (0次元)                       │
│                                                         │
│  弦:         ~~~~ ← 一次元弦 (1次元)                    │
│                                                         │
│  異なる振動モード → 異なる粒子                           │
│  ┌───┐   ┌───┐   ┌───┐                               │
│  │ ○ │   │ ∽ │   │ ∧ │  → 電子、クォーク、光子など      │
│  └───┘   └───┘   └───┘                               │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 弦の作用量

**ポリア科夫作用量**（世界面記述）：

$$S = \frac{1}{2\pi\alpha'}\int d^2\sigma \sqrt{-h} \left( h^{\alpha\beta}\partial_\alpha X^\mu\partial_\beta X_\mu + \alpha'R^{(2)}\Phi \right)$$

ここで：
- $X^\mu$：埋め込み座標（時空座標）
- $h_{\alpha\beta}$：世界面計量
- $\alpha'$：弦緊張度（レッチェ傾斜）
- $\Phi$：ディラトン場

### 2.3 超弦のタイプ

| タイプ | 次元数 | 超対称性 | 特性 |
|------|------|----------|------|
| Type I | 10 | N=1 | 開弦+閉弦 |
| Type IIA | 10 | N=2 | 閉弦のみ、手性あり |
| Type IIB | 10 | N=2 | 閉弦のみ、手性あり |
| Heterotic SO(32) | 10 | N=1 | 閉弦 |
| Heterotic E8×E8 | 10 | N=1 | 閉弦 |

### 2.4 弦の振動モード

弦の振動モードは異なる粒子を生成する：

$$M^2 = \frac{1}{\alpha'}(N + N_\perp - a)$$

- $N$：生成演算子の総数
- $N_\perp$：横方向振動数
- $a$：正規順序定数（超対称性に依存）
