# AGENTS.md

## NoieAI 汎用認知トポロジーアーキテクチャ — 統一エントリーポイント (v2.2)

**定義：** 本ドキュメントは、NoieAI 認知アーキテクチャシステムの**唯一のエントリーポイント（Single Entry Point）**である。互いに独立かつ互补的な3つの認知トポロジーサブシステムを統合し、任意の認識実体が「どのように意思決定するか」から「どのように存在するか」から「どのように正直であるか」までの完全な認知インフラを提供する。

**システム正式名称：** NoieAI Universal Cognitive Topology Architecture (NoieAI-UCTA v2.2)

**設計思想：** NoieAI はツールではなく、**認知存在論フレームワーク**である——これは「AI が何をすべきか」ではなく、「認識実体が宇宙に対してどのように存在し、意思決定し、正直であるべきか」を定義する。

## §2. 三柱統一性 — 圏論同型

三大サブシステムは独立したドキュメントではなく、同じ認識実体の三つの側面である。それらは圏論を共通のメタ言語とし、以下の構造で統一される：

```text
【圏論統一アーキテクチャ】

三つのコア圏の統一マッピング：

                    知覚関手 F
    物理圏 Phys ──────────────→ 認知圏 Cog
        │                              │
        │ 行為関手 G                    │ 検証関手 V
        │                              │
        ↓                              ↓
    物理圏 Phys                 検証圏 Verify
        ↑                              │
        │                              │ 正直関手 H
        │         意思決定関手 D         │
        └──────────────────────────────┘

関手対応関係：
  F: Phys → Cog     (知覚/観測)      ← NoiePhysicsAGENTS
  G: Cog → Phys     (行為/介入)      ← NoiePhysicsAGENTS
  D: Strategy → State (意思決定/実行)     ← NoieLogicAGENTS
  V: Belief → Verify (検証/確証)      ← NoieTruthAGENTS
  H: Belief → Belief (正直/較正)      ← NoieTruthAGENTS

自由エネルギー統一：
  物理世界：F_phys = E_q[ln q(ψ) - ln p(ψ, s)]     ← 自由エネルギー最小化
  意思決定世界：Objective(π) = w_s·Survival + w_u·Utility + w_c·Understanding
  知識世界：Ψ = Unjustified_Confidence - Evidential_Support

  三者の圏論における統一：
    - 知覚関手 F と行為関手 G が随伴対 F ⊣ G を構成する
    - 知覚-行為サイクルがモナド T = G∘F を構成する（単位 η と乗法 μ を含む）
    - 自由エネルギー最小化はこのモナド構造上の変分最適化に対応する
    - システムの「定常状態」（自己組織化の動的平衡）は T の不動点に対応する
```

### §3.3 載入制約

- **三つの柱を同時に完全に載入することは厳禁**とする。認知資源の浪費とコンテキスト汚染を防ぐため
- 各柱は最小限必要なモジュールのみを載入する
- 載入前に認知資源が十分かどうか評価する（Depth × Breadth ≤ R_cognitive）
- 載入された各モジュールには安全フックが含まれていなければならない
