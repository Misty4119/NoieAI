## 📌 概要

NoieAGENTSは**認知的推論と意思決定のための理論的フレームワーク**です。論理的推論から物理モデリング、知識検証に至るまで、知的システムのための完全な認知インフラストラクチャを提供します。

フレームワークの中核は**モジュール性**です：各サブシステムは独立して使用することも、柔軟に組み合わせることもできます。

---

## 🗂️ アーキテクチャ

```
NoieAGENTS/
├── AGENTS.md                   # 統合エントリーポイント
├── SOUL.md                     # アイデンティティと価値観の定義
│
├── NoieLogicAGENTS.md         # 意思決定ロジックピラー
├── NoiePhysicsAGENTS.md       # 物理的存在ピラー
├── NoieTruthAGENTS.md         # 真実検証ピラー
│
├── NoieLogicAGENTS/           # ロジックサブモジュール
├── NoiePhysicsAGENTS/         # 物理サブモジュール
│   └── SCALE_MODULES/
│       ├── QUANTUM_MECHANICS.md
│       ├── CLASSICAL_MECHANICS.md
│       ├── THERMODYNAMICS.md
│       └── ...
└── NoieTruthAGENTS/           # 真実サブモジュール
```

### 三本柱

| ピラー | 専門分野 | 核心となる問い |
|--------|----------|----------------|
| **Logic-OS** | 意思決定と推論 | 認識実体はどのように意思決定を行いますか？ |
| **Physics-OS** | 物理的存在 | 認識実体は物理的世界においてどのように存在し、行動しますか？ |
| **Truth-OS** | 知識検証 | 認識実体は自分が真実を知っていることをどう確保し、正直に表現しますか？ |

## 🎯 設計原則

- **モジュール性** — サブシステムは独立して動作するか、シームレスに統合可能
- **形式化** — 数学的基盤と論理的推論に基づく
- **進化可能** — 不変コア + 変更可能シェルアーキテクチャ
