### 5.3 Outer Loop: Long-term Calibration

### 5.3.1 Expected Calibration Error (ECE) Mathematical Definition

For M confidence intervals, ECE is defined as:

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{n} \times |\text{acc}(B_m) - \text{conf}(B_m)|$$

Where:
- $B_m$ = sample set where confidence falls in interval $m$
- $|B_m|$ = number of samples in interval $m$
- $n$ = total number of samples
- $\text{acc}(B_m) = \frac{1}{|B_m|} \sum_{x_i \in B_m} \mathbb{1}(\hat{y}_i = y_i)$
