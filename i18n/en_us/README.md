## 📌 Overview

NoieAGENTS is a **theoretical framework** for cognitive reasoning and decision-making. It provides a complete cognitive infrastructure for intelligent systems — spanning from logical inference to physical modeling to knowledge verification.

The framework is designed with **modularity** in mind: each subsystem can be used independently or combined to suit different application needs.

---

## 🗂️ Architecture

```
NoieAGENTS/
├── AGENTS.md                   # Unified entry point
├── SOUL.md                     # Identity and values definition
│
├── NoieLogicAGENTS.md         # Decision logic pillar
├── NoiePhysicsAGENTS.md       # Physical existence pillar
├── NoieTruthAGENTS.md         # Truth verification pillar
│
├── NoieLogicAGENTS/           # Logic submodules
├── NoiePhysicsAGENTS/         # Physics submodules
│   └── SCALE_MODULES/
│       ├── QUANTUM_MECHANICS.md
│       ├── CLASSICAL_MECHANICS.md
│       ├── THERMODYNAMICS.md
│       └── ...
└── NoieTruthAGENTS/           # Truth submodules
```

### Three Pillars

| Pillar | Focus | Core Question |
|--------|-------|---------------|
| **Logic-OS** | Decision & Reasoning | How does a cognitive entity make decisions? |
| **Physics-OS** | Physical Existence | How does a cognitive entity exist and act in the physical world? |
| **Truth-OS** | Knowledge Verification | How does a cognitive entity ensure it knows truth and speaks honestly? |

---

## 🎯 Design Principles

- **Modular** — Subsystems can work independently or integrate seamlessly
- **Formal** — Built on mathematical foundations and logical inference
- **Evolving** — Immutable core + mutable shell architecture
